# Sakib's ICT HTML Practice Lab

An interactive, student-friendly HTML learning and practice app by Sakib's ICT.

## About the Project

Sakib's ICT HTML Practice Lab is designed to help students learn HTML through Bengali tutorials, hands-on coding practice, and instant output previews.

The project can be packaged as an Android application using a WebView wrapper.

## Features

- **HTML Code Editor:** Write and practice HTML code.
- **Live Preview:** See the output of your HTML code instantly.
- **Bengali Tutorials:** Learn HTML concepts in Bengali.
- **Practice Tasks:** Improve coding skills through practical exercises.
- **Quiz:** Test your understanding of HTML.
- **Examples:** Explore sample HTML code.
- **Offline Support:** Core learning and practice features are designed to work
