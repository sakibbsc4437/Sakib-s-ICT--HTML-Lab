# Sakib's ICT - HTML Practice Lab 🚀

Welcome to the **Sakib's ICT - HTML Practice Lab** mobile application repository! This project hosts an Android WebView wrapper built to provide an interactive learning environment for HTML practice.

---

## 📱 Features

* **Interactive WebView:** Smooth rendering of HTML practice materials.
* **Custom Branding:** Designed with custom app icons and themes.
* **Automated Builds:** Built automatically into Android APKs using GitHub Actions workflows.

---

## 🛠️ Tech Stack & Requirements

* **Platform:** Android (Java / AndroidX)
* **SDK Version:** Minimum SDK 21 / Target SDK 33
* **Build System:** Gradle with GitHub Actions CI/CD
